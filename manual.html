操作手冊

「文字整理編輯器」把貼上或上傳的雜亂草稿，交給 AI（固定內建「資深文件排版編輯與文字精煉師」人設）整理成帶一、二、三級標題階層、段落精煉、錯字/標點已校對的正式文件，並保留原有表格；整理後的內容可直接在畫面上編輯，最後下載成 Word（.docx）檔案。

操作步驟

  1. 在左側「輸入內容」貼上要整理的雜亂草稿，或按「上傳 .txt / .docx」讀入既有檔案內容（.docx 內含的表格也會一併帶入）
  2. 展開「API 連線設定」，選擇服務商（Claude／OpenAI／Gemini／OpenRouter）並填入你自己申請的 API 金鑰——金鑰只存在你的瀏覽器
  3. 填入金鑰後，「額外需求」欄位與 5 個快速提示詞會自動解鎖，可點選或自行填寫這次整理的特殊要求（例如濃縮成一頁重點、強調數據）
  4. 按「✨ 整理內容」：有填金鑰會呼叫 AI 產生帶標題階層的整理結果；沒有填金鑰則自動改用陽春規則式整理（只整理段落間距與保留表格，不會產生標題）
  5. 右側「整理後內容」可直接點選文字修改，或用上方工具列（一/二/三級標題、內文、粗體、斜體）調整格式
  6. 按「⬇️ 下載 Word」把目前畫面上的內容匯出成 .docx 檔案
「整理內容」每次都會覆蓋右側整理結果，若想保留目前版本，請先下載 Word 或複製內容備份，再重新整理。

AI 功能（選用，需自備 API 金鑰）

展開「API 連線設定」，填入你自己申請的 API 金鑰；模型欄有預設值，也可以自行改成想用的模型 ID。

  • AI 會依固定內建的排版校對人設，把原始文字加上一、二、三級標題、精簡冗長段落、修正錯別字與標點，並在整理結果下方附上一段「本次調整說明」
  • 若原始內容或上傳的 .docx 中含有表格，AI 會盡量保留為表格，不會拆散成一般段落文字
  • 「額外需求」欄位可補充這次整理的特殊要求（例如語氣、篇幅、重點方向），5 個快速提示詞可直接套用或自行修改
  • 沒有填 API 金鑰時，「整理內容」會改用陽春規則式整理——只合併換行、去除多餘空白、保留原有表格，不會產生標題階層或改寫文字
API 金鑰要自己到各服務商網站申請，使用時依你與該服務商的方案計費，本工具不會向你收費，也不會經手你的金鑰——金鑰只存在你這台電腦的瀏覽器，且直接連到服務商官方 API，不會經過本工具以外的任何伺服器。

可直接編輯的輸出區

  • 整理後的內容顯示在一個可編輯的白色文件卡片中，點一下即可直接修改文字
  • 選取一段文字後，按上方工具列的「一級標題／二級標題／三級標題／內文」可調整該段落的階層；「粗體／斜體」可調整選取文字的樣式
  • 「📋 複製內容」會複製目前輸出區的純文字；「🧹 清空重來」會清空輸入與輸出（會先跳出確認）

隱私說明

  • 你貼上或上傳的內容、整理結果、API 金鑰都只存在自己瀏覽器的 localStorage 或畫面上，不會傳送到任何伺服器；重新整理頁面或清除瀏覽器資料會遺失尚未下載的內容，請自行用「下載 Word」備份重要內容
  • 按下「整理內容」且已填金鑰時，你貼上的原始內容會直接連線送到你選擇的服務商官方 API，不會經過本工具作者或任何第三方伺服器

使用警語

請注意：
  • AI 整理結果（尤其是標題階層與改寫段落）僅供參考，請自行核對內容，特別是數字、金額、日期、人名等關鍵資訊
  • 請勿輸入真實個資、公司機密、他人受著作權保護的內容，或不希望被 AI 服務留存的敏感資訊
  • 使用 AI 功能所產生的 API 費用由你與所選服務商的方案自行負擔，本工具不會向你收費
  • 本工具與創作者不對使用本工具後所得之任何內容或後續決策結果負責
